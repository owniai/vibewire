# Aim

Clarify through interview, record domain language and decisions, then synthesize and route.

## Scope

CRITICAL: ONLY explore and analyze — NEVER write or modify source code — route for implementation.

Phase references: ALWAYS read on phase entry — NEVER pre-read.

## Before Start

Read `.vibewire/project.md` — if missing, prompt `/vibewire:intro`. Follow its **Vibewire artifacts** pointers, then enter Grill.

## Process

### Phase 1: Grill

ALWAYS on entry: read [grilling](grilling.md) and [domain-modeling](domain-modeling.md) — one loop.

NEVER proceed to Synthesize until the frontier is empty and the user confirms shared understanding.

### Phase 2: Synthesize

ALWAYS ask on entry (recommendation: persist when the work may span sessions or hand off to go/plan):

- **Summarize** — read [synthesize](synthesize.md)
- **Skip** — proceed to Route.

### Phase 3: Route

ALWAYS read [route](route.md) for routing to implementation.
